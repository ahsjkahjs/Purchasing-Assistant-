# 报价归一化与质量价格评分

## 1. 先归一化价格

`normalized_total_cost` 必须对应同一需求数量、同一币种和同一交付口径。按报价实际项计算：

```text
产品总价
+ 税费口径调整
+ 运输与保险
+ 包装
+ 模具/调试/安装等本批费用
+ 其他必须支出
- 明确折扣
= 归一化总成本
```

不得把缺失费用默认成 0。汇率必须记录来源和日期；未税与含税、出厂与到厂、样品与批量报价未统一前不得排名。寿命、能耗、备件等可可靠量化时，可另做 TCO 修正，但须保留计算依据。

## 2. 质量分 0–100

质量分评的是**本次报价中可核验的证据**，不是企业名气。建议细分：

| 子项 | 分值 | 给分依据 |
|---|---:|---|
| 技术规格符合度 | 30 | 逐项响应、偏离表、图纸/选型确认；关键项不满足应直接排除 |
| 材料与工艺可验证性 | 20 | 材质牌号、关键工序、过程控制及可追溯记录 |
| 检测与认证 | 20 | 与本次产品相关且有效的检测、认证、验收标准；不相关证书不计分 |
| 质量保证与售后 | 15 | 质保范围、响应、备件、退换/整改责任 |
| 追溯与交付质量证据 | 15 | 批次追溯、出厂检验、可核验的类似项目验收材料 |

每个子项在 `notes` 或证据中保留理由。只有“厂家直销”“质量第一”等宣传语时对应项不得给满分。关键安全/法规项不满足时，应 `eligible=false`，而不是靠其他高分抵消。

## 3. 脚本评分

有效报价间计算：

- `价格分 = 最低归一化总成本 / 本家归一化总成本 × 100`；
- `交期分 = 最短交期 / 本家交期 × 100`；
- `商务分 = 50 × min(本家质保/目标质保, 1) + 50 × min(本家账期/目标账期, 1)`；
- `质量分`、`完整性分`直接采用经证据审查的 0–100 分；
- `总分 = Σ(归一化权重 × 分项分) - 风险扣分`，最低截为 0。

默认权重：价格 40%、质量 35%、交期 10%、商务 10%、完整性 5%。权重可按采购目标调整，但不得为了指定某家中标而事后改权重。

## 4. 风险扣分

- 0：未见额外风险；
- 1–5：轻微偏离、次要材料缺失或需一次澄清；
- 6–15：异常低价、较大技术偏离、售后模糊等显著风险；
- 16 以上：通常应直接设为不合格，而非仅扣分。

风险理由必须写入 `notes` 或 `exclusion_reason`。价格显著低于其他家时先核查漏项、材质、数量、税运和付款口径，不直接视为优势。

## 5. 候选规则

至少 2 家有效报价才输出候选；默认取总分前 3，只有 2 家则取 2 家。报告同时呈现价格、质量、交期、排除原因和证据，禁止只给总分。最终定点、合同、付款和下单均由人工决定。
