# 供应商背景调查：维度、公开来源与评分口径

背调的目的是回答一个问题：**这家公司究竟是不是它自己说的那家公司**。所有结论必须能追溯到公开来源，查不到就写"未查到"，禁止推测。

## 铁律

1. **只用公开来源**：政府公示平台、企业官网、公开年报、法院公告、公开招投标、行业协会稿件、正规资讯报道。
2. **不做什么**：不查个人身份证、隐私电话、家庭信息；不通过非正规渠道买数据；不做任何需要登录/绕过防护/付费爬虫的动作；不调用 APP 内部接口。
3. **每条结论一条来源**：`source_url` + `source_date` 缺一不可；同一维度有多个来源就写多条 finding，不要合并成一句"据说"。
4. **区分"未查到"和"不存在"**：查不到不等于没有，写 `"status": "未获得公开证据"`，不加推测性负面结论。
5. **不与前面的成本/报价结论混算**：背调只算综合实力分，不参与报价评分；两者在最终人选里分开呈现。
6. **牌照类资质以发证机关公示为准**，不等于对方自己贴出来的证书图片。

## 八个维度与建议关键词

| 维度 | 要看什么 | 常用公开来源 |
|---|---|---|
| 工商与实控 | 统一社会信用代码、注册资本/实缴、成立年限、经营范围是否含制造、实控人与股东、社保缴纳人数、地址是否异常 | 国家企业信用信息公示系统 `gsxt.gov.cn`；商业公示平台（企查查/天眼查）的免费公开页 |
| 司法与失信 | 失信被执行人、限制高消费、裁判文书、开庭公告、经营异常、股权冻结、行政处罚 | 中国执行信息公开网 `zxgk.court.gov.cn`；信用中国 `creditchina.gov.cn`；裁判文书网 `wenshu.court.gov.cn` |
| 产能与设备 | 产线型号与数量、年产能、厂区占地、员工规模、是否有熔铸/轧制/加工母机、是否外协 | 官网"公司简介/生产设备"页；政府采购/招标文件的企业资质描述；上市公司年报产能章节 |
| 资质与认证 | ISO9001/14001、行业认证、产品执行标准、第三方检测报告、特殊行业许可 | 认证机构公示（认监委 `cnca.gov.cn` 查询体系证书）；官网资质页需注明证书编号 |
| 客户与业绩 | 典型客户、公开案例、中标记录、出口国家、是否有长期大客户背书 | 招投标公示 `bidcenter.com.cn`；官网案例页；展会/协会报道（注明时间） |
| 出口与履约 | 进出口经营权、外贸团队、装箱包装能力、公开交期承诺、退换货政策 | 海关企业信用信息公示 `credit.customs.gov.cn`；官网"外贸/出口"页 |
| 财务与开票 | 能否开 13% 专票、年报营收与资产、涉税违法记录、注册资本实缴比例 | 企业年报（公示系统）；税务机关公告；电商平台注册资本公示 |
| 风险信号 | 低于成本线的引流价、同名公司混淆、平台标签与工商范围矛盾、负面舆情、地址异常 | 前面各步已收集的价格样本与工商数据交叉比对；正规媒体报道 |

> 针对某个具体品类，把"常用公开来源"替换成该品类的行业协会目录、认证目录、产业带园区公示等更有针对性的来源。

## 评分口径（1–5 分，整数）

| 分数 | 含义 |
|---|---|
| 5 | 公开证据充分且为正面的实质性证据（政府/发证机构/上市公司披露） |
| 4 | 两个及以上独立来源佐证，或官网有可核验编号的证书/产线清单 |
| 3 | 只有一般性公开信息、或未核实的自述（含"未查到"按 `unverified_score` 计） |
| 2 | 证据薄弱、自相矛盾，或关键项（经营范围含"批发"却自称工厂）无法证明 |
| 1 | 存在明确负面证据或关键项缺失且可能误导（如曾被列入经营异常未移出） |

缺失维度按 `missing_dimension_score` 计分，并在报告中标注"该维度未做调查"，避免缺项被误读成高分。

## 综合实力总分

- 单家总分 = Σ(维度权重 × 维度得分) ÷ Σ已评维度权重，再换算到 100 分制；
- 只看已评维度，未调查维度不参与分母，但要单独列出说明覆盖度；
- **红线优先于分数**：命中任一 redline 的厂家，直接标注"建议剔除/暂缓定点"，即使总分第一也不进推荐。

## 一票否决（redline）典型情形

1. 被列为失信被执行人、限制高消费、经营异常未移出，或存在股权冻结/严重违法失信记录；
2. 近三年有重大质量、安全生产或环保处罚，且公示仍在有效期内；
3. 自称生产厂家但无任何生产证据，且不能提供所供批次的原厂材质单/质量证明（贸易商身份可以接受，但不能冒充厂家）；
4. 实缴出资、社保人数、厂房规模与其宣称的产能/规模明显不符。

## 报告呈现要求

- 先给**综合实力排名表**（公司、总分、强项三项、风险三项、红线状态、建议）；
- 再给**逐家明细**（每个维度：结论摘要、分数、来源链接与日期、是否触发 redline）；
- 最后给**待核验清单**：必须由对方提供原件核对的事项（营业执照、开票资料、证书编号、材质单、近三个月质检记录）。
