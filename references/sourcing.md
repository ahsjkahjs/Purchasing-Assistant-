# 供应商寻源与公开联系方式规范

## 1. 先定品类，再检索

把用户口语化产品名转换为：

- 标准品名、常见别名、英文名；
- 型号、规格、材质、产能、工艺等限定词；
- 上游原料和下游用途；
- 3–5 个产业带或目标区域；
- 如适用，记录 HS 编码，但不确定时不得猜测。

检索式示例：`城市 + 产品 + 生产厂家`、`产品 + 环评 + 公司`、`产品 + 展会 + 参展商`、`产品 + 联系我们`。付费“十大厂家”榜单只可作线索，不可作排名证据。

## 2. 来源优先级

1. 企业官网及官方联系方式页；
2. 国家企业信用信息公示、环评、排污许可、招投标等公开材料；
3. 行业协会、展会参展商名录；
4. B2B 店铺、工厂档案和公开招聘信息；
5. 地图、行业媒体和垂直网站。

主体名称与经营方向应尽量由两个独立来源交叉核验。只出现于招商软文的企业需要降级或标待核验。

## 3. 厂家等级

| 等级 | 判据 | 使用方式 |
|---|---|---|
| A | 经营范围含制造/生产，且有厂房、产线、环评、排污许可、生产招聘等佐证 | 可优先谈产能、质量和价格 |
| B | 有生产迹象，但证据不完整或规格仍需确认 | 首轮问自产/外协和关键工序 |
| C | 仅见销售、批发、贸易或流通证据 | 可作渠道，不冒充生产厂家 |

等级是证据强弱，不是企业好坏。`match_score` 另评 1–5 的规格匹配度，不与厂家等级混用。

## 4. 联系方式规则

- 仅记录公开的业务电话、业务邮箱和公开微信号；不收集私人社交账号或非公开个人信息。
- 电话、邮箱、微信号逐项填写 `contact_sources` 来源 URL；主来源 `source_url` 不能替代逐项来源。
- 查不到写 `未公开`。不得根据姓名、公司名、区号或邮箱格式推测。
- 400/800 标为客服；招聘电话标来源和用途，不冒充采购直线。
- 记录 `source_date`。使用前重新打开来源核验主体和号码。
- 同一电话或微信出现在多家公司时保留数据但给警告，人工排查代账、招商平台或集团总机。

## 5. 清单分层

按项目需要分为龙头、中坚、区域专精，并给 1–5 匹配度。寻源用于实际采购时优先匹配度与可交付性，不把企业规模直接当作首选理由。

## 6. 联系边界

脚本只输出人工队列。逐个核验主体、合理控制频次、提供真实采购身份和退出选择。不得购买来路不明的微信号数据，不得使用群控、模拟点击、接码或绕过验证码/风控的方式批量操作。
