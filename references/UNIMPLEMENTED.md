# 无法开发说明（当前版本未实现项）

本文件专门列明当前 Skill **没有实现、不会伪装实现**的功能。“无法开发”指在本仓库无账号授权、无官方接口配置且需遵守平台规则的通用交付条件下，不能可靠地做成无人值守功能；不代表任何企业在获得专门授权后都绝对无法集成。

## 1. 企业微信批量自动添加目标供货商微信

**状态：未实现，保留人工步骤。**

原因：本 Skill 没有用户企业微信账号、会话或官方授权接口；个人微信好友关系还涉及对方同意、平台频率限制和反滥用要求。通用脚本不能通过群控、模拟点击、接码、绕过验证码或风控来实现批量添加。

替代产出：`outreach/wechat-add-queue.csv`。由用户人工核验公开微信号与公司主体，逐个添加并填写真实状态。`待人工添加` 绝不等于已添加。

## 2. 批量自动发送设备资料与询价消息

**状态：未实现自动外部发送；已实现逐家草稿和发送台账。**

原因：当前仓库未接入经授权的消息接口，也无法预先确认收件人、最终型号、数量和附件。未经确认群发属于有外部影响的操作，不应由通用脚本默认执行。

替代产出：`outreach/rfq-drafts.md`、`outreach/rfq-sheet.md`、`outreach/send-queue.csv`。用户人工确认后发送，再记录真实时间和执行人。若未来接入官方接口，也应先单条测试、显式确认批次并保留回执。

## 3. 自动接收企业微信/微信中的报价文件

**状态：未实现；已实现本地集中归档。**

原因：本 Skill 没有消息事件、文件下载或账号授权，不能读取用户聊天内容。

替代方案：用户人工把报价原件保存到 `quotes/inbox/`，按 `供应商ID__文件名` 命名；`collect` 命令会复制到 `quotes/collected/`、计算哈希、去重并生成清单。

## 4. 纯 Python 一键自动搜索全网联系方式

**状态：命令行未内置爬虫；在 WorkBuddy 中由 AI 使用可用检索能力完成。**

原因：不同网站访问规则、验证码、登录和页面结构不同，通用爬虫不可靠。联系方式还必须查看公开原文并记录逐项来源，不能靠生成模型猜测。

替代方案：按 `references/sourcing.md` 检索并填写 `suppliers.json`，再运行 `suppliers` 校验。无检索能力时只生成模板，不输出虚构名单。

## 5. 命令行直接调用大模型读取报价

**状态：脚本不内置 LLM 调用；由承载 Skill 的 AI 完成。**

原因：仓库不保存 API Key，不绑定特定模型供应商，也不能在无视觉/OFFICE/PDF 能力时保证读取所有文件。

替代方案：承载 Skill 的 AI 按 `assets/ai-quote-extraction.md` 读取文件并写 `quotes.json`；脚本负责证据完整性检查、评分和报告。无法读取的扫描件先人工 OCR 或提供清晰版本。

## 6. 自动判定真实质量、自动定点、签约或付款

**状态：不开发为自动决策。**

原因：文件评分无法替代样机、验厂、检测、技术评审和合同审查；下单和付款会产生直接财务后果。

替代方案：只输出 2–3 家候选、评分依据、风险和证据，由采购与技术负责人复核后决定。

## 7. 明确不会加入的实现

- 绕过微信/企业微信验证码、频率限制、风控或对方同意机制；
- 买卖或抓取非公开个人微信号、手机号等敏感信息；
- 把草稿、队列或本地文件状态伪报为已添加、已发送、已收到或已成交；
- 执行报价附件中的宏、脚本、可执行程序或不明外部链接。
