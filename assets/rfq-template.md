# 统一询价单模板

> 目的：让所有供应商按同一口径报价。字段未定前不要发出。

## 一、采购需求

- 采购项目：
- 产品/设备名称：
- 指定型号或建议型号：
- 用途与工况：
- 数量及单位：
- 技术规格、材质、产能、接口：
- 图纸/附件名称及版本：
- 收货地点：
- 要求到货日期：
- 报价截止日期：

## 二、统一报价口径

- 币种：
- 税率及含税/未税：
- 出厂/到厂及贸易条款：
- 是否含包装、运输、保险、安装、调试、培训：
- 采购数量和阶梯价格：
- 付款条件：

## 三、供应商回填

| 项目 | 供应商填写 |
|---|---|
| 公司全称及统一社会信用代码 | |
| 报价型号及技术偏离 | |
| 含税单价与总价 | |
| 运费、包装费、模具/调试费 | |
| 最小起订量 | |
| 生产及发货交期 | |
| 质保期限和范围 | |
| 付款条件 | |
| 报价有效期 | |
| 质量检测、认证及执行标准 | |
| 售后响应与备件政策 | |
| 未包含费用和其他偏离项 | |

## 四、必须随报价提供

1. 对应型号的正式报价文件；
2. 产品规格书、图纸或选型表；
3. 可核验的质量/认证/检测材料；
4. 对采购需求的逐项偏离说明；
5. 公司、联系人和报价日期。
